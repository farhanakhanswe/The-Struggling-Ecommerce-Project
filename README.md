## The Struggling Ecommerce Project

This project is an attempt to build a full-stack e-commerce platform from scratch without using any third-party frameworks, libraries and packages. 

The goal is to struggle through the engineering challenges that modern frameworks and libraries solve to deepen my engineering knowledge.

For this project, I'm choosing tools that I'm already familiar with. I will strictly use HTML, CSS, vanilla JS, raw PHP, and MySQL for the development.

At the moment, this project will be monolithic and will follow MVC architecture combined with the Service-Repository pattern.

In the process of building this, I'm also building a separate project which is a live server built using Node.js.
This is so that I can quickly see the html changes without having to manually reload the browser.

Link: https://github.com/farhanakhanswe/Live-Server
