# The Struggling Ecommerce Project

## This project is an attempt to build a full-stack ecommerce platform from scratch without using any third-party frameworks, libraries and packages. 

## The goal is to struggle through the engineering challenges that modern frameworks and libraries solve to deepen my engineering knowledge.

## For this project, I'm choosing tools that I'm already familiar with. I will strictly use HTML, CSS, JS, PHP, and MySQL for the development.
